## 📱 Performance & Optimization

### Mobile Optimization
- **Disabled on mobile/tablet:**
  - Cursor trail (no mouse)
  - Light rays (performance)
  - Bubbles (performance)
  - Sparkles/fireflies (performance)
  - Photo corner animations (touch interface)

- **Simplified on mobile:**
  - Shimmer animations slower (6s vs 4s)
  - Text shadows removed
  - Fewer simultaneous animations

### Performance Features
- **Visibility API:** Pauses animations when tab is hidden
- **Throttling:** Cursor trail throttled to 50ms
- **Intersection Observer:** Animations only when elements are visible
- **Cleanup:** Particles auto-remove after animation
- **Prefers-reduced-motion:** Respects accessibility settings

### Browser Optimization
- CSS `will-change` on animated elements
- Transform3D for GPU acceleration
- RequestAnimationFrame for smooth timing
- Debounced resize handlers

## 🎯 Design Philosophy

All enhancements follow these principles:

1. **Elegant, Not Overwhelming** - Effects are subtle and enhance the romantic theme
2. **Performance First** - Optimized for smooth 60fps, reduced on mobile
3. **Accessible** - Respects prefers-reduced-motion
4. **Tasteful** - Appropriate for a wedding invitation
5. **Responsive** - Adapts to screen size automatically
